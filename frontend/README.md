# Frontend

React and TypeScript dashboard shell for the Hybrid Retail BI system.

Implemented screens include login, protected dashboard layout, role-aware navigation, master data management for products, suppliers, categories, and branches, plus the inventory table, stock detail panel, adjustment modal, and movement history.

## Run Locally

```powershell
cd frontend
npm install
npm run dev
```

Local URL:

```text
http://localhost:5173
```

Demo login after running the backend seed script:

```text
admin@hybridretail.test
RetailDemo@123
```
